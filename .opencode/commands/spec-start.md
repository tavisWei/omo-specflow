# Spec Start

Launch a structured development workflow using the Spec Kit methodology.

## Workflow Phases

1. **Constitution** - Define project vision, values, and constraints
2. **Specify** - Gather detailed requirements via interview
3. **Plan** - Create actionable implementation plan
4. **Tasks** - Break down into executable tasks
5. **Implement** - Execute with continuous verification

## Interview

Before generating the specification, I need to understand your project better. Please answer:

### Project Overview
1. What type of project is this?
   - Web application / Mobile app / Backend service / API / CLI tool / Library / Other

2. What domain or industry does this serve?
   - E-commerce / Social / Finance / Healthcare / Education / Entertainment / Productivity / Other

3. Who are the target users?
   - B2C customers / B2B enterprises / Internal team / Developers / End consumers / Other

### Core Features
4. What is the primary functionality this project must deliver?
   - [List top 3-5 features in order of priority]

5. What makes this project different from existing solutions?
   - [Unique value proposition]

### Technology Stack
6. Preferred frontend technologies?
   - React / Vue / Svelte / Angular / Vanilla JS / Other

7. Preferred backend technologies?
   - Node.js / Python / Go / Rust / Java / .NET / Other

8. Database preferences?
   - PostgreSQL / MySQL / MongoDB / Redis / SQLite / None / Other

9. Any specific libraries or frameworks already chosen?

### Integrations
10. Third-party services needed?
    - Payment gateways / Authentication providers / Cloud storage / Analytics / Email / SMS / Other

11. External APIs to integrate with?

### Non-Functional Requirements
12. Performance expectations?
    - Response time targets / Concurrent users / Data volume

13. Security requirements?
    - Compliance standards / Authentication needs / Data encryption

14. Deployment environment?
    - Cloud provider / Self-hosted / Edge / Mobile stores

## Next Steps

After gathering this information, I will generate a specification document using the template at `.opencode/spec-templates/01-需求文档.md` and then proceed with planning and implementation.
