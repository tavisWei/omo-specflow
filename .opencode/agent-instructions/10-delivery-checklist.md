# 交付检查清单（Delivery Checklist）

> 本文档定义完成阶段的最终交付标准，确保多 Agent 输出可以被稳定接收和继续维护。

## 1. 交付包应包含

- 完整 spec 文档集
- TASKS.md 最终版本
- QA evidence 文件
- 覆盖率/审查结果
- 已知限制说明

## 2. 最终检查

- [ ] 所有 required 文档已生成
- [ ] 关键条款已被任务覆盖
- [ ] 关键任务有证据文件
- [ ] spec-review 无 blocking issues
- [ ] README 或使用说明已同步

## 3. 交付摘要格式

```markdown
## Delivery Summary
- Scope completed:
- Key evidence:
- Remaining non-blocking items:
- Recommended next iteration:
```
