## 认证授权

### 认证方式

> 提示：选择或描述API使用的认证机制

- [ ] **Bearer Token** - JWT Token认证
- [ ] **API Key** - API密钥认证
- [ ] **OAuth 2.0** - OAuth授权
- [ ] **Cookie** - 基于Cookie的会话认证
- [ ] **签名认证** - 请求签名验证

### 认证流程

> 提示：描述认证的整体流程，包括获取token的方式、有效期限、刷新机制等

```
1. 客户端使用凭证（用户名/密码、API Key等）获取访问令牌
2. 在请求头中携带令牌：Authorization: Bearer <token>
3. 服务器验证令牌有效性
4. 令牌过期时，使用刷新令牌获取新令牌
```

## 请求规范

### 请求头

| 请求头 | 必填 | 说明 | 示例 |
|--------|------|------|------|
| Content-Type | 是 | 内容类型，固定值 | `application/json` |
| Authorization | 是 | 认证令牌 | `Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...` |
| X-Request-ID | 否 | 请求唯一标识，用于追踪 | `req_abc123` |
| X-Timestamp | 条件 | 请求时间戳（签名认证时必填） | `1699999999` |

### 请求参数位置

| 方法 | 参数位置 | 说明 |
|------|----------|------|
| GET | Query String | URL查询参数 |
| POST | Request Body | JSON请求体 |
| PUT | Request Body | JSON请求体 |
| PATCH | Request Body | JSON请求体 |
| DELETE | Query String | URL查询参数 |

## 响应规范

### 响应结构

所有接口统一使用以下响应结构：

```json
{
  "code": 0,
  "message": "success",
  "data": null,
  "requestId": "req_abc123",
  "timestamp": "2024-01-01T12:00:00Z"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| code | integer | 状态码，0表示成功，非0表示错误 |
| message | string | 状态描述信息 |
| data | object/array/null | 响应数据体 |
| requestId | string | 请求唯一标识 |
| timestamp | string | 响应时间（ISO 8601格式） |

### 响应码说明

| 状态码 | 含义 | 说明 |
|--------|------|------|
| 0 | 成功 | 请求成功 |
| 400 | 请求错误 | 参数格式错误、缺少必填参数等 |
| 401 | 未认证 | 未提供认证信息或认证信息无效 |
| 403 | 无权限 | 已认证但无访问权限 |
| 404 | 资源不存在 | 请求的资源不存在 |
| 409 | 资源冲突 | 资源状态冲突，如重复创建 |
| 422 | 业务错误 | 请求格式正确但业务逻辑无法处理 |
| 429 | 请求过于频繁 | 触发限流 |
| 500 | 服务器错误 | 服务端内部错误 |

## 错误码定义

> 提示：为每个模块定义专属错误码，格式：模块(2位) + 编号(3位)

### 通用错误码 (0xxxx)

| 错误码 | 说明 | 处理建议 |
|--------|------|----------|
| 0 | 成功 | - |
| 40001 | 参数错误 | 检查请求参数格式和必填性 |
| 40002 | 参数校验失败 | 查看errors字段获取详细校验信息 |
| 40101 | 未授权 | 提供有效的认证凭证 |
| 40102 | Token过期 | 使用刷新令牌获取新Token |
| 40103 | Token无效 | 重新登录获取新Token |
| 40301 | 无权限 | 联系管理员申请相应权限 |
| 40302 | 资源归属错误 | 无法操作不属于自己的资源 |
| 40401 | 资源不存在 | 检查资源ID是否正确 |
| 40901 | 资源冲突 | 检查是否重复创建或状态冲突 |
| 42901 | 请求限流 | 降低请求频率，等待后重试 |
| 50001 | 服务端错误 | 重试或联系技术支持 |
| 50002 | 服务维护中 | 等待服务恢复 |

### [模块A]错误码 (1xxxx)

> 提示：为资源A定义专属错误码

| 错误码 | 说明 | 处理建议 |
|--------|------|----------|
| 10101 | [模块A] 错误描述 | [建议操作] |
| 10102 | [模块A] 错误描述 | [建议操作] |

### [模块B]错误码 (2xxxx)

> 提示：为资源B定义专属错误码

| 错误码 | 说明 | 处理建议 |
|--------|------|----------|
| 20101 | [模块B] 错误描述 | [建议操作] |

## 接口定义模板

### 接口定义格式

每个接口按以下格式描述：

```markdown
### X.X 接口名称
> 提示：描述这个接口的作用、业务场景、调用频率限制等

**接口地址**
```
{HTTP方法} /api/v1/{资源路径}
```

**请求头**
| 请求头 | 必填 | 说明 |
|--------|------|------|
| Authorization | 是 | Bearer Token认证 |

**请求参数**

> 提示：说明参数的来源（Path/Query/Body）和校验规则

| 参数名 | 位置 | 类型 | 必填 | 说明 | 校验规则 |
|--------|------|------|------|------|----------|
| id | Path | string | 是 | 资源ID | 非空，长度不超过64 |
| page | Query | integer | 否 | 页码 | 默认1，最小1 |
| pageSize | Query | integer | 否 | 每页数量 | 默认20，范围1-100 |
| fieldA | Body | string | 是 | 字段A | 非空，最大长度100 |
| fieldB | Body | array | 否 | 字段B | 数组最大长度50 |

**请求示例**
```json
{
  "fieldA": "示例值",
  "fieldB": ["选项1", "选项2"]
}
```

**响应参数**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| id | string | 资源ID |
| name | string | 资源名称 |
| status | string | 状态 |
| createdAt | string | 创建时间 |
| updatedAt | string | 更新时间 |

**响应示例**
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "id": "res_123456",
    "name": "示例资源",
    "status": "active",
    "createdAt": "2024-01-01T12:00:00Z",
    "updatedAt": "2024-01-01T12:00:00Z"
  }
}
```

**错误码**

| 错误码 | 说明 |
|--------|------|
| 40001 | 参数错误 |
| 40101 | 未授权 |
| 40401 | 资源不存在 |
| 50001 | 服务端错误 |

---
```

| 类型 | 说明 | 示例 |
|------|------|------|
| string | 字符串 | `"hello"` |

| 字段名 | 类型 | 说明 |

| createdBy | string | 创建人ID |
| updatedBy | string | 更新人ID |
