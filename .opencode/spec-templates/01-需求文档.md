## Specify（详细规格）

### 用户故事格式
每条用户故事必须包含：ID、标题、角色、行为、价值

```
US-XXX: [简短标题]

**角色 Role**: [谁在做这件事]
**行为 Behavior**: [具体做什么]
**价值 Value**: [为什么重要，解决了什么问题]
**优先级 Priority**: [P0/P1/P2]
**故事点 Story Points**: [1/2/3/5/8]
```

#### 示例
```
US-001: 快速搜索商品

**角色 Role**: 购物用户
**行为 Behavior**: 输入关键词后在1秒内看到相关商品列表
**价值 Value**: 节省时间，提高购物效率，避免流失到其他平台
**优先级 Priority**: P0
**故事点 Story Points**: 5
```

### 验收标准格式
每条验收标准必须可测试、可观察、可量化

```
AC-XXX: [描述]
**测试方式**: [如何验证]
**通过条件**: [具体指标]
```

#### 示例
```
AC-001: 搜索结果应在1秒内显示
**测试方式**: 在Chrome DevTools Network面板测量API响应时间
**通过条件**: P95响应时间 < 1000ms

AC-002: 搜索无结果时应显示友好提示
**测试方式**: 输入"xyzabc123"验证
**通过条件**: 显示"未找到相关商品，建议检查关键词"
```
